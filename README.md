# ESP32 Anti-Tamper Smart Parcel Monitoring System

## Overview

An ESP32-based smart parcel monitoring system designed for tamper detection and environmental monitoring.

## Components

- ESP32
- MPU6050
- LDR
- DHT11
- OLED Display

## Features

- Tamper detection using motion sensing
- Light-based tamper detection
- Temperature and humidity monitoring
- OLED-based status display

## Technologies

- ESP32
- Embedded C
- MPU6050
- LDR
- DHT11
- OLED
